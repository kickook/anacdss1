# 麻醉生命体征智能预警平台

基于 Flask 构建的全流程麻醉安全协同系统。平台支持多手术间配置、设备 API 集成、用药信息管理，并在生命体征超出阈值时调用 Dify LLM 给出干预建议，帮助麻醉医生快速做出决策。

## 功能亮点

- **多手术间管理**：为每个手术间配置监护仪、注射泵、麻醉机等设备及其参数。
- **阈值预警与联动**：灵活设置参数阈值，自动检测并生成预警记录。
- **患者与用药档案**：维护患者基础信息、麻醉用药清单和术中记录。
- **Dify 智能建议**：在生命体征异常时将现场信息推送至 Dify，获取针对性建议。
- **科技感前端界面**：可视化展示多源参数、预警记录和推荐意见，支持模拟数据流验证流程。

## 完整手术麻醉系统建设蓝图（参考国内外主流实践）

为满足中国医院临床使用场景，系统建议覆盖“术前-术中-术后”全流程，并与院内信息系统互联互通。以下蓝图可作为需求对齐与方案设计的基线，兼顾国内（如麦迪斯顿、大成等厂商的常见能力）与国际主流麻醉信息系统实践。

### 1. 业务域与功能模块

- **术前评估与排程**
  - 手术排班、麻醉评估、风险分层（ASA 等）、过敏史与合并症管理。
  - 术前检查/检验结果拉取与结构化摘要，术前知情同意与术前准备清单。
  - 麻醉方案模板、气道评估、禁食禁饮与用药禁忌提醒。
- **术中麻醉记录**
  - 生命体征采集（监护仪、麻醉机、呼吸机、泵类设备）。
  - 用药与输液记录、体温/出血量/尿量等输入输出记录。
  - 关键事件与并发症记录、麻醉深度与镇痛评估。
  - 手术进程事件轴（入室、诱导、插管、切皮、拔管、出室）。
- **术后恢复（PACU）**
  - 评分量表（如 Aldrete）、镇痛泵与术后镇痛随访。
  - 术后并发症与不良事件上报闭环。
  - 镇痛/镇静评估与交接班记录。
- **用药与耗材管理**
  - 麻醉药品规范化字典与临床路径、药品批次追溯与麻精药管理。
  - 麻醉设备耗材与一次性材料管理（管路、气道、输注耗材）。
- **质量与科研**
  - 质控指标（术中低温、低氧、低血压事件）统计。
  - 报表、科研数据集导出与脱敏管理。
  - 多维度看板（科室/医生/手术类型）与趋势追踪。

### 2. 设备集成与数据采集

- **多厂商协议适配**：统一设备适配层，兼容串口/网络协议、HL7 v2、IHE-PI/DEC 等常见接口。
- **采集容错与校验**：断线重连、离线缓存、数据去噪与时间对齐，保证数据连续性。
- **参数字典标准化**：统一单位、阈值范围、参数编码（如 SpO₂、EtCO₂、BIS）。
- **数据采样策略**：关键参数高频采样、事件驱动写入，减少存储压力。

### 3. 与医院信息系统的对接

- **HIS/EMR/LIS/PACS 互联**：患者主索引（MPI）、手术排班、检验检查结果与病历联动。
- **费用与收费接口**：麻醉耗材与药品自动计费。
- **权限与审计**：与统一身份认证/单点登录（SSO）对接，满足审计追踪。
- **标准与规范**：兼容 HL7/FHIR、IHE 以及国内互联互通标准。

### 4. 安全与合规

- **数据安全**：等保 2.0、最小权限、全量审计、备份与灾备演练。
- **隐私合规**：患者隐私保护与数据脱敏导出策略。
- **医疗器械协同**：设备接入与数据处理过程留痕，满足临床合规与追责要求。
- **业务连续性**：主备/容灾切换、关键接口降级与故障告警。

### 5. 关键流程闭环

- **从排班到归档**：排班→评估→术中记录→PACU→出院随访→病历归档。
- **异常预警闭环**：阈值触发→提示确认→干预记录→事后分析。
- **质量控制闭环**：指标异常→原因分析→改进计划→效果评估。
- **设备维护闭环**：点检→校准→故障→维修→复测。

### 6. 建议的技术架构演进

- **核心服务**：设备接入网关、实时数据流、规则引擎、麻醉业务服务、报表/BI 服务。
- **数据层**：实时库 + 结构化数据仓库，支持临床、科研与质控。
- **扩展能力**：AI 建议、临床路径推荐、趋势预测与智能告警。

### 7. 关键角色与使用场景

- **麻醉医生**：术前评估、术中记录、异常干预记录、术后随访。
- **护士/技师**：设备接入与参数确认、交接班、耗材与用药核对。
- **质控人员**：指标监控、异常复盘、月/季度报表。
- **信息科/工程师**：系统集成、设备适配、数据治理。

### 8. 建设路线建议

1. **一期（基础可用）**：术中记录 + 生命体征采集 + 告警 + 术后 PACU。
2. **二期（流程闭环）**：术前评估、耗材计费、质控指标与报表。
3. **三期（智能提升）**：AI 建议、临床路径、科研数据平台与多院区支持。

> 如果需要将该蓝图落地为完整产品，可基于本项目现有的监测与告警能力，优先补齐“术前评估、PACU 管理、药品与耗材、质控指标与报表”四大模块，并逐步开展院内系统集成。

## 快速开始

1. **准备环境**
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **设置环境变量（可选）**
   - `DATABASE_URL`：默认使用项目根目录下的 SQLite 数据库，可根据需要指向 MySQL。
   - `DIFY_API_URL` 与 `DIFY_API_KEY`：配置后即可启用 Dify 联动。

3. **启动应用**
   ```bash
   flask --app run.py run
   ```
   访问 `http://127.0.0.1:5000` 打开监测工作台。

4. **模拟流程**
   - 左侧新增手术间并配置设备/阈值（可通过 API）。
   - 选择手术间，录入患者与用药资料后启动监测。
   - 点击“模拟采集数据”即可演示阈值告警与 Dify 建议的联动。

## API 概览

- `POST /api/rooms`：创建手术间。
- `POST /api/rooms/<room_id>/devices`：为手术间接入设备。
- `POST /api/devices/<device_id>/parameters`：注册监测参数。
- `POST /api/parameters/<parameter_id>/threshold`：配置阈值。
- `POST /api/patients`：创建患者档案。
- `POST /api/sessions`：启动监测会话。
- `POST /api/sessions/<session_id>/ingest`：写入实时参数并自动触发预警。
- `GET /api/alerts`：查看最新预警列表。

详细请求/响应示例可参考 `wxcloudrun/views.py` 中的注释实现。
